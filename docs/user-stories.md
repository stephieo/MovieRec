# MovieRec - User Stories

## User Stories by Epic

### Epic 1: User Authentication & Profile Management
- **US-1.1**: As a new user, I want to register an account with username, email, and password so I can access personalized movie recommendations and save favorites
- **US-1.2**: As a registered user, I want to log in securely using my credentials to access my personal data and preferences  
- **US-1.3**: As a user, I want to view my profile information (username, email, join date) to verify my account details
- **US-1.4**: As a user, I want my login session to persist securely so I don't have to re-authenticate frequently

### Epic 2: Movie Discovery & Search
- **US-2.1**: As a user, I want to see trending movies for the current week so I can discover popular and current content
- **US-2.2**: As a user, I want to search for specific movies by title so I can find movies I'm interested in
- **US-2.3**: As a user, I want to view  movie information so I can make informed viewing decisions
- **US-2.4**: As a user, I want to get movie recommendations based on a selected movie so I can find similar content I might enjoy


### Epic 3: TV Series Discovery & Search
- **US-3.1**: As a user, I want to browse trending TV series for the current week so I can discover popular shows
- **US-3.2**: As a user, I want to search for TV series by title so I can find specific shows
- **US-3.3**: As a user, I want to view TV series information to understand the show's content
- **US-3.4**: As a user, I want to get TV series recommendations based on a selected show so I can find similar series


### Epic 4: Favorites Management
- **US-4.1**: As a user, I want to add movies to my favorites list so I can easily find them later
- **US-4.2**: As a user, I want to add TV series to my favorites list so I can keep track of shows I enjoy
- **US-4.3**: As a user, I want to view all my favorite movies and TV series in one organized list with poster images
- **US-4.4**: As a user, I want to remove movies or TV series from my favorites when I'm no longer interested in them
- **US-4.5**: As a user, I want to prevent accidentally adding the same content to favorites multiple times
- **US-4.6**: As a user, I want my favorites to include movie/show titles and poster images automatically so I can recognize them easily

### Epic 5: Performance & User Experience  
- **US-5.1**: As a user, I want the app to respond quickly (under 2 seconds) so I have a smooth browsing experience
- **US-5.2**: As a user, I want search results and movie data to load fast even when many people are using the app
- **US-5.3**: As a user, I want the app to work reliably even if external movie services are temporarily unavailable
- **US-5.4**: As a user, I want clear and helpful error messages when something goes wrong so I understand what happened
